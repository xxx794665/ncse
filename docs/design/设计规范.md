# ncse 设计规范

> 状态：定稿（2026-10-07，T0-02）。本文件是全站 UI/VI 的唯一权威来源；视觉样式的取舍以本文件为准，代码规范见 docs/工程规范.md。
> 依据：ADR-0006（设计系统先行、现代教育产品风、暗色三态）。
> **§9 的 token 对照表是 T0-03（design tokens 与主题三态）的实现契约**：变量名、语义、亮/暗数值必须逐一落地，不得改名、不得缺值。

## 1. 设计原则

1. **效率优先**。备考是高频、长时段的工具型使用：首屏直达做题，任何核心操作（开始刷题、继续上次、看错题）不超过两次点击；表单默认值给足，能记住的选择不让用户重选；PC 与移动端的常用操作都必须落在拇指/鼠标热区内。
2. **激励但不游戏化**。用「可见的进步」激励：正确率趋势、掌握度、连续打卡以克制的方式呈现（统计徽章、进度条）。不做排行榜、不做积分商城、不做夸张动效与拟物奖杯——它们消耗备考者有限的注意力。
3. **长阅读高可读性**。题干与材料是本站被阅读时间最长的内容：阅读列宽受限（约 34 个中文字/行）、行高宽松、字重不滥用、材料与题目分区清晰。一切排版决策在冲突时让位于阅读体验。
4. **一致性先于惊艳**。所有页面复用 §6 组件与 §9 token；新需求先在既有 token 内解决，确需新增 token 时回本文件补登记。
5. **暗色是一等公民**。暗色不是亮色的反色滤镜：阴影、边框、强调色在暗色下单独取值（见 §9），备考者夜间刷题不伤眼。

## 2. 色彩体系

### 2.1 取色策略

- **主色（Primary）**：蓝色系（Blue）。蓝色是教育产品的共识色——理性、可信、降低焦虑；与「正确=绿、错误=红」的判分语义不冲突。
- **中性色（Neutral）**：石板灰（Slate）色阶，带轻微冷调，与主色同源，保证界面干净不发闷。
- **语义色**：成功=绿、警告=琥珀、危险=红、信息=天蓝。语义色只承载状态含义，不做装饰。
- 基础色板（§9 表 A）为**主题无关的常量**；语义 token（§9 表 B）按亮/暗取不同值，所有界面只引用语义 token，禁止直接引用基础色板。

### 2.2 使用规则

- 正文级文字与其背景的对比度 **≥ 4.5:1**（WCAG AA）；大号文字（≥ 18px 或 14px 粗体）≥ 3:1；图标、边框、焦点环等非文本要素 ≥ 3:1。
- `--color-text-tertiary` 仅允许出现在 `bg-base` / `bg-subtle` / `bg-elevated` 上；在 `bg-muted` 底色（如徽章、填充块）上至少使用 `--color-text-secondary`（tertiary/muted 亮色组合为 4.34:1，不达标）。
- 语义色成对使用：`--color-*-soft`（浅底）必配 `--color-*-soft-text`（其上文字）；单独的文字/图标用 `--color-*-text`；填充块（如标签实心）用 `--color-*` 配反色文字。
- 暗色下强调色整体提亮一档（400 级）以保证深色底上的对比度；主按钮填充亮暗一致（`#2563EB`），其上文字恒为白色（5.17:1）。
- 暗色下禁止大面积纯黑/纯白；层级靠「底色微亮 + 边框 + 阴影」表达（见 §4.4）。

## 3. 字体体系

### 3.1 字族

- 中英混排用**系统字族栈**（§9 表 D `--font-family-sans`）：西文走系统无衬线，中文回退 PingFang SC / Microsoft YaHei / Noto Sans SC。不引入 Web 字体：自用站点，加载速度与离线可用优先。
- 数字与计时器用 `--font-family-mono`，并强制 `font-variant-numeric: tabular-nums`——倒计时、统计数据跳动时不抖。

### 3.2 字号 / 行高阶梯

阅读层级三级（§3.3）之外的全局阶梯见 §9 表 D。行高用**无单位倍数**，随字号缩放；长文一律用 `--line-height-loose`（1.8）。

### 3.3 题目阅读三级层次

| 层级 | 内容 | 字号 / 行高 | 字重 | 颜色 |
|---|---|---|---|---|
| 一级·题干 | 题干（stem） | `--font-size-stem` 17px / 1.7 | medium 500 | text-primary |
| 二级·选项 | 选项 A–D、填空输入 | `--font-size-option` 16px / 1.625 | regular 400 | text-primary |
| 三级·材料 | 题组材料、篇章阅读正文 | `--font-size-material` 16px / 1.8 | regular 400 | text-primary（不降级颜色，材料同样要求 4.5:1） |

- 元信息（来源 qid/年份/卷型、难度、用时）用 `--font-size-aux` 13px + text-tertiary。
- 解析正文用 `--font-size-body` 16px / 1.75。
- 加粗只用于题干中的设问句、解析中的结论句，禁止整段加粗。

## 4. 间距、栅格、断点、圆角与阴影

### 4.1 间距

4px 基准的间距阶梯（§9 表 E `--spacing-*`）。组件内部用 2xs–md；卡片与区块之间用 lg/xl；页面级节奏用 2xl/3xl。禁止阶梯之外的任意像素值（1px 边框除外）。

### 4.2 栅格与断点

| 断点 | 范围 | 布局 |
|---|---|---|
| 移动（默认，移动优先） | < 768px | 4 列，槽 16px，页边距 16px；底部 Tab 导航 |
| 平板 | 768–1023px | 8 列，槽 24px，页边距 24px；沿用底部 Tab |
| PC | ≥ 1024px | 12 列，槽 24px；顶栏导航，内容居中 |

- 页面内容最大宽 `--layout-max-content` 1200px；**阅读流最大宽 `--layout-max-reading` 760px**（题干、材料、解析单列阅读不撑满宽屏，约 34 个中文字/行）。
- 刷题页 PC 允许「材料左栏 + 题目右栏」双栏（≥ 1024px 时启用，栏比 5:7），移动端材料折叠为顶部可展开抽屉（见 §7.2）。

### 4.3 圆角

`--radius-*` 阶梯（§9 表 E）：控件 sm（6px）、卡片 lg（12px）、模态/抽屉 xl（16px）、胶囊与头像 full。同一容器内圆角一致，嵌套时内层 ≤ 外层。

### 4.4 阴影

四级 `--shadow-*`（§9 表 E，亮/暗分别取值）：sm=卡片静止、md=悬浮卡片/下拉、lg=模态与抽屉、xl=顶栏吸顶浮起。暗色下阴影加深（透明度提高）并**必须配合 1px `--color-border-subtle` 边框**表达层级——暗色底间亮度差仅 1.2:1，单靠阴影不可辨。

## 5. 图标语言

- 图标库：**lucide-react**（MIT、SVG、树摇；与 React 技术栈一致，见架构设计 §2）。
- 尺寸阶梯：16（行内/徽章）/ 20（按钮、导航、表单）/ 24（空状态、功能入口）px；`strokeWidth` 恒为 2，与字重 medium 视觉等重。
- 颜色：跟随上下文 `currentColor`；表意图标用对应 `--color-*-text`，纯装饰图标用 text-tertiary。
- 规则：①图标不单独承载关键操作含义，危险/判分类操作必须带文字；②装饰性图标 `aria-hidden="true"`，独立图标按钮必须 `aria-label`；③同一含义全站同一图标（收藏=Star、错题=CircleX、计时=Timer、解析=BookOpen、设置=Settings、打卡=CalendarCheck、统计=ChartColumn、占位页=Construction）。

## 6. 组件形态规范

> 组件实现归 T0-04；本节定义形态与 token 引用，组件 API 设计时不得偏离。

### 6.1 按钮 Button

| 变体 | 形态 | 用途 |
|---|---|---|
| primary | 填充 `--color-primary`，文字白；hover `--color-primary-hover`，active `--color-primary-active` | 每屏至多一个主操作（提交答案、开始模考） |
| secondary | bg-elevated 底 + 1px border-default，文字 text-primary；hover 底色转 bg-muted | 次操作（暂存、加入错题） |
| ghost | 无底无边，文字 primary-text；hover 底 primary-soft | 列表内操作、工具栏 |
| danger | 填充 `--color-danger`，文字白；hover danger-700/#B91C1C（暗 #DC2626） | 不可恢复操作（清空记录、删除账号数据），必须二次确认 |

- 尺寸：sm 高 32/字号 14/px-12；md 高 40/字号 15/px-16（默认）；lg 高 48/字号 16/px-24（移动端主操作）。
- 圆角 `--radius-sm`；禁用态透明度 0.5 + `cursor: not-allowed`；加载态左侧 16px 旋转图标，宽度锁定不抖动。
- 焦点环：2px `--color-border-focus` + 2px 偏移，全控件统一。

### 6.2 卡片 Card

bg-elevated + border-subtle 1px + `--radius-lg` + shadow-sm；hover（可点击卡片）升 shadow-md 并上移 2px（`--duration-fast`）。内边距 PC `--spacing-lg`、移动 `--spacing-md`。卡片标题用 `--font-size-title` + semibold。

### 6.3 输入 Input / Textarea

高 40（单行默认）/ 48（移动表单）；bg-base + border-default，hover border-strong，focus 焦点环；占位文字 text-tertiary；错误态边框 `--color-danger` + 下方 13px danger-text 错误说明；禁用态 bg-muted。标签在输入框上方，14px medium。

### 6.4 导航

- **PC 顶栏**（≥ 1024px）：高 64px，bg-elevated + 底边 border-subtle，吸顶（sticky）时加 shadow-xl。左：产品名「ncse」+ 主导航（刷题/模考/错题本/统计/计划）；右：主题切换（lucide Sun/Moon/Monitor 三态循环）、账号入口。当前页导航项文字 primary-text + 底部 2px primary 指示条。
- **移动底部 Tab**（< 1024px）：高 56px + 安全区，bg-elevated + 顶边 border-subtle。五个 Tab：刷题（BookOpen）、错题（CircleX）、统计（ChartColumn）、计划（CalendarCheck）、我的（User）。激活态图标+文字 primary-text，未激活 text-tertiary。
- 二级页面移动端用顶部返回栏（高 48px，左箭头 ChevronLeft + 页面标题）。

### 6.5 题目卡片 QuestionCard

刷题流中的单题容器：Card 基础上，头部为「题号 + 元信息（qid/年份/难度，aux 字号 text-tertiary）+ 收藏/标记图标按钮」，中部题干（§3.3 一级），下部选项区（§7.1），底部解析区（§7.4，默认折叠）。选项与选项间距 `--spacing-sm`。

### 6.6 统计徽章 StatBadge

小颗粒成就/数据展示：图标 16 + 数值（mono、semibold）+ 标签（aux、text-tertiary），横向排列，高 32px，bg-muted + `--radius-full` 内边距 px-12。语义着色仅用于图标（如连续打卡用 warning-text 火焰 Flame），数值恒 text-primary。

### 6.7 占位页 Placeholder

未实现功能页（ADR-0006）：垂直居中，lucide `Construction` 48px text-tertiary + 标题「功能建设中」+ 一句说明（该功能所属里程碑）+ secondary 按钮「返回首页」。不写死预计上线时间。

### 6.8 反馈件（补充约定）

- Toast：右上（移动顶部居中），bg-inverse + text-inverse + `--radius-md` + shadow-lg，成功/失败左侧语义色图标，4s 自动消失。
- 空状态：图标 48px text-tertiary + 一句引导文案 + 可选引导按钮。
- 骨架屏：bg-muted 圆角块 + 1.2s 呼吸动画，替代一切整页 spinner。

## 7. 题目内容排版规范

### 7.1 题干与选项

- 题干段前距 `--spacing-md`，多段落间距 `--spacing-sm`；题干中的**设问句**（"这段文字意在说明"）单独成段并 semibold。
- 选项纵向列表（永不横排）：每项 = 选项字母徽标（A–D，20px 圆形、border-default、medium）+ 选项文本，行间距 `--spacing-sm`，整项为点击热区（最小高 44px）。
- 选项状态：
  - 默认：bg-elevated；
  - hover（未判分）：bg-muted；
  - 选中：底 `--color-primary-soft`、文字 `--color-primary-soft-text`、字母徽标填充 primary 文字白；
  - 判分·正确：底 `--color-success-soft`、文字 `--color-success-soft-text`、徽标 success；
  - 判分·误选：底 `--color-danger-soft`、文字 `--color-danger-soft-text`、徽标 danger；
  - 判分·未选的正确项：同「正确」态并加 1px success 描边，提示漏选。
- 判分后选项禁点；解析区自动展开（§7.4）。

### 7.2 长材料阅读

- 材料块：bg-subtle + 左 3px `--color-border-strong` 侧线 + 内边距 `--spacing-lg`，`--radius-md`；正文按 §3.3 三级（16px/1.8），列宽 ≤ `--layout-max-reading`。
- 材料超一屏：PC 双栏（§4.2）材料栏独立滚动、顶部 sticky 显示「材料」标签；移动端默认折叠为首屏预览（约 3 行）+「展开材料」，展开后覆盖式抽屉可从顶部下滑关闭，阅读进度在题目区保持可见锚点。
- 篇章阅读（一材料多题）：小题间切换不重置材料滚动位置。

### 7.3 图片与公式插槽

- 题目富片段 = 文本段 + 插槽（架构设计 §4 的富片段模型）。**图片插槽**：块级居中、最大宽 100%、最大高 480px、懒加载、`--radius-md` 边框 border-subtle；点击全屏查看（捏合缩放）；加载中显示骨架块（固定 4:3 占位防跳动）。**公式插槽**：KaTeX 渲染；行内公式随文字流，独立公式块级居中、上下 `--spacing-md`；渲染失败回退显示原始 LaTeX 源码（mono 字号 14）。
- 图片与公式颜色必须暗色可读：公式用 text-primary 渲染；底色透明。

### 7.4 答案与解析

- 解析区在选项之下，以 1px border-subtle 分隔，标题行「答案与解析」+ 展开/折叠 ChevronDown。
- 展示顺序固定：①**答案行**：「正确答案：C」semibold + success-text；你的选择对错徽章；②**解析正文**（§3.2）；③逐项辨析（正确项为何对、干扰项为何错），每项以字母徽标引导；④**知识点标签行**：关联知识点以 ghost 徽章列出（bg-muted + 13px），点击进知识点练习。
- 模考模式下解析区整卷交卷前完全隐藏（连折叠入口都不显示），防止泄题。

## 8. 主题三态

### 8.1 定义

- 用户可选模式 `mode ∈ { system, light, dark }`；**默认 `system`**。
- 实际生效主题 `resolved ∈ { light, dark }`：`mode=system` 时取 `prefers-color-scheme` 的当前值，否则取 `mode`。
- 持久化：`mode` 写入 localStorage 键 `ncse-theme-mode`；未写入时视为 `system`。`resolved` 不落盘、每次实时求值。

### 8.2 行为

- **系统偏好变化**（`matchMedia('(prefers-color-scheme: dark)')` change）：仅当 `mode=system` 时立即跟随切换；`mode` 为 light/dark 时忽略系统变化。
- **切换时机**：主题切换（手动或跟随系统）即时生效、全站无刷新；切换时给 `color`/`background-color`/`border-color`/`box-shadow` 加一次性过渡（`--duration-normal`），通过 `<html>` 上的临时类（如 `.theme-transition`）实现，600ms 后移除，避免加载期过渡闪烁。
- **FOUC 防护**：入口 HTML 的 `<head>` 内联一段无依赖脚本，在首绘前读取 localStorage + prefers-color-scheme 算出 `resolved` 并写 `<html data-theme="light|dark">`；CSS 变量按 `[data-theme='dark']` 覆盖亮色默认值（`:root` = 亮色）。该脚本是 T0-03 的必备交付。
- `<meta name="theme-color">` 随 `resolved` 更新（亮 `#FFFFFF` / 暗 `#0F172A`），移动端地址栏/状态栏同色。
- 设置页「外观」用三选一分段控件（跟随系统 / 亮 / 暗，图标 Monitor/Sun/Moon）；PC 顶栏的主题按钮为循环切换的快捷入口，点击顺序 system → light → dark → system，图标即当前 `mode`。

## 9. Token 对照表（T0-03 实现契约）

命名约定：基础色板为常量（亮暗同值，仍双列给出以示完整）；语义 token 亮暗异值。实现方式：`apps/web` 内 CSS 自定义属性，`:root` 定义亮色，`[data-theme="dark"]` 覆盖暗色（§8.2）。**本表数值与 §2.3 实测对比度一一对应，改值必须同步复算对比度并更新两表。**

### 契约条款

1. T0-03 必须逐一落地本表全部变量（`:root` 亮色 + `[data-theme="dark"]` 暗色），缺一个暗色值即验收不通过。
2. 组件（T0-04 起）只引用表 B–E 的语义 token；新增 token 必须先回本文件登记再使用。
3. 主题机制按 §8 实现：`ncse-theme-mode` 持久化、默认 `system`、首绘前内联脚本防 FOUC。
