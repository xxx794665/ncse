# ADR-0011：视觉提取范围收敛为题干与选项（解析缺省可入）

日期：2026-10-18　任务：T1-18（T1-17 vision 节奏决策落地，用户选 B）　状态：已采纳

## 背景

ADR-0008 定义的 visionText 按题原子回写要求题目**全部**宿主图片段（题干/选项/解析）都有文本才回写，提取范围为全部 38,053 个内容寻址键。真实题库实测（T1-17）暴露成本约束：视觉子代理单键成本约 41–46k tokens（带放大核实）/轻量模式约 7.1k，全量约 15 亿 tokens，配额主导需数月不可行；键分布中 **84% 为纯解析宿主**——它们只影响解析内配图的可搜索性，不影响作答。用户在「全量 / 题干+选项优先 / 暂缓」三选项中选 **b（题干+选项优先）**。

## 决策

1. **宿主分两级**：题干与选项为**必选宿主**——任一段未就绪（未键路径/pending/error）该题不回写（保留按题原子，防半截）；解析为**可选宿主**——文本在手则并入拼接、缺失不阻塞该题回写（「解析缺省可入」）。
2. **提取范围（pending/批次/工件存在性检查）只覆盖必选键**：被任意题目的题干或选项引用过的键才进 `vision-manifest.json` 的 pending（纯解析键出范围、不做 artifact 检查）；`vision 0 = 无 error 且无 pending` 的退出语义随之以必选范围为准。纯解析键已有的提取文本仍入 entries 缓存（幂等保留，opportunistic 并入）。
3. **解析类图片的全量补齐推迟**至外部视觉 API（ADR-0008 第 4 条后置扩展，M4 AI 设置就绪后）——届时成本降数量级，直接按缓存键续跑，无需再改管线语义。

## 后果

- 推翻 ADR-0008 决策 3 中「全部宿主任一段缺文本即不回写」的表述（吸收/staging/缓存协议不变）；vision.test.ts 同步改造。
- 做题相关的图片题（题干/选项，约 6 千键）先获得可搜索文本；解析内配图在补齐前以 R2 图片直接渲染可见（现状），仅 visionText 缺其文字。
- 题干/选项与解析共享的键天然在范围内（必选引用优先），解析文本随批次一并吸收。
