# 图片资产内容寻址与产物路径重写

题库约 3.9 万张题目图/公式图的 R2 对象键采用原始字节 sha256 内容寻址（位图压缩后为 `img/<64 位十六进制>.webp`，gif 动图原字节透传为 `.gif`）：同内容图片天然去重，幂等重跑与再蒸馏后重导入键不变，源文件更名/移动不影响键。路径重写只发生在 JSON 中间产物（题干/选项/解析/材料图片段 path 原位替换为键，alt 保留），源文件定位失败（路径越界/文件缺失/类型不支持/工件缺失）仅记 error 级 issue 且该段保持源路径——失败局部化、不中断其余图片，重新 parse 后重跑即自愈。DB 恒存裸键（`img/…`），访问 URL 由服务层统一构造：不把 R2 公共基址或 API 路由耦合进数据，换域名/路由/缓存策略不动数据；R2 上传为管线独立后续阶段（产物目录 r2/ 即待传工件区，本 ADR 只定键派生与重写语义）。

上传路径定稿（T1-05 阶段 B 实现遵循）：经 node 直启仓库根 `node_modules/wrangler/bin/wrangler.js` 执行 `r2 object put <bucket>/<key> --file <对象键> --content-type <mime>`（本地态冒烟加 `--local`；--file 传相对键、进程 cwd = r2 工件根，绝对路径不进 argv），参数数组直传并显式 shell:false、桶名/对象键/mime 三层白名单校验（防旗标伪装参数注入）、凭据走 wrangler 本机 OAuth（源码零凭据，bucket 名是 CLI 参数）；产物目录 `r2/` 为待传工件区（上传口径 = 该目录全部非隐藏文件，与段引用解耦；点开头条目视为工具自身状态如 --local 本地态）；put 幂等覆盖（内容寻址同键同字节），带 `--bucket` 重跑 = 全量重传，语义安全。
