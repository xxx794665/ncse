# 0012 试卷实体与题目多卷归属

日期：2026-10-21 · 状态：已采纳（M2 启动，用户按规划草稿建议基线放行）

## 决策

题库新增「试卷（paper）」实体，题目与试卷为**多对多归属**（`papers` + `question_papers`）：
题目实体仍全局唯一（qid 去重不变），但一份卷的完整题集 = 该卷在源仓库中出现的全部 qid（含与其他卷共享的联考同题）。

## 为什么

- T1-04 导入管线「全局 qid 去重保首见并同步清理题组引用」把联考同题的归属**独占给首见卷**。2026-10-21 探查（任务索引当日条目）：515 卷中 315 卷实际题量低于原卷题数、206 卷损失 ≥100 题、8 卷近乎清空——F2-1「按年份/地区/卷型选择真题整卷」在单归因数据形态下无法取回联考卷完整题集。
- 题目本体都在库中，仅归属缺失；改为多对多即可恢复，题目去重与内容寻址等既有幂等机制零改动。
- 归属信息以**独立产物文件**（parse 阶段输出 `papers.json`）承载，modules/*.json 结构不动——images/vision 阶段与 vision 缓存（内容寻址键）完全不受影响，管线幂等重跑即可完成再蒸馏（符合 ADR-0007/0008 的既有原则）。

## 后果

- 推翻 T1-04 的单归因设计（去重仍保留，仅归属改多对多）；db 阶段新增 papers/question_papers 幂等 upsert 与孤儿清理。
- 试卷题序为近似口径：模块目录序 → 文件内 items 序（源数据无整卷题号元数据）；真实卷模块顺序与该口径不符的卷后续可按卷校正。
- `mock_sessions` 挂 paperId（restrict 防级联删历史成绩，同蓝图哲学）随 T2-01b 落地。
