# 任务索引

> **开工先读本表取任务；收工或配额中断前必须把状态、进度、下一步写回本表。**
> 任务状态：`未开始` `进行中` `已完成` `受阻` `已取消`。
> 拆片规则：临近执行的里程碑拆到执行粒度；远期里程碑保持功能级，启动时再拆（见 docs/工作流-多模型协作.md）。
