# ncse — 公务员考试练习网站

面向 PC 与移动端的自用备考平台：行测/申论刷题、复习与模拟练习。目标考试 **2027 省考**（约 2027 年 3 月）。规划先行、按里程碑交付，多模型分工协作开发。

> **当前状态**：**M1（行测刷题 MVP）进行中**——T1-01 API 骨架、T1-02 D1 数据模型（27 表）、T1-03 认证（注册/登录/JWT + 测试）、T1-04 导入管线文本模块（Markdown 解析 + 幂等编排 + 29 用例）已完成，当前推进 T1-05（图片资产管线：压缩 → R2 → 路径重写）。M0 设计系统已全部收口（独立验收通过）。进度见 [docs/任务索引.md](./docs/任务索引.md)。

## 协作者上手

1. 先读 [CONTEXT.md](./CONTEXT.md) 统一术语，再读 [docs/任务索引.md](./docs/任务索引.md) 确定当前阶段与下一个任务。
2. 遵守 [CLAUDE.md](./CLAUDE.md)（文档同步、安全约束、配额收尾是硬性规则）。
3. 里程碑顺序：**M0 设计系统 → M1 行测刷题 MVP → M2 整卷模考 → M3 知识点体系 → M4 申论 → M5 学习计划 → M6 组卷与间隔重复 → 二期（面试/软考/AI 增强）**。
4. 每日配额触达限额即收尾，次日 09:50 由定时任务「每天9点50续跑ncse项目」续跑；整体开发完成后该任务自删。
