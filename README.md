## 协作者上手

1. 先读 [CONTEXT.md](./CONTEXT.md) 统一术语，再读 [docs/任务索引.md](./docs/任务索引.md) 确定当前阶段与下一个任务。
2. 遵守 [CLAUDE.md](./CLAUDE.md)（文档同步、安全约束、配额收尾是硬性规则）。
3. 里程碑顺序：**M0 设计系统 → M1 行测刷题 MVP → M2 整卷模考 → M3 知识点体系 → M4 申论 → M5 学习计划 → M6 组卷与间隔重复 → 二期（面试/软考/AI 增强）**。
4. 每日配额触达限额即收尾，次日 09:50 由定时任务「每天9点50续跑ncse项目」续跑；整体开发完成后该任务自删。
